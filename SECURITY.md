# Security Policy

## Supported Versions

Security fixes are applied to the latest released version only.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/rjspencer/zygo-cms/security) of this repository and choose **Report a vulnerability**.

Include as much of the following as you can:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- The affected version and package

You can expect an initial response within a few days. Please give us reasonable time to release a fix before any public disclosure.
